# LINE投稿の中身調査：取る価値のある投稿はどれか（2026-10-04）

撮影済み148店舗・1,188件（9/25〜10/2）を店舗ごとに並べて目で見た結果。
取材告知は /slot 側で取れているので対象外。新台・増台も他から取れるので優先しない。

## 結論

- 大半の店舗の投稿は「明日9時開店」「抽選時刻」「感謝」「週末」「会員アプリ」などの営業告知で、取る価値は低い。
- 価値がありそうなのは、**夕方〜夜に、機種だけを見せる画像を日替わりで送ってくる店舗**。翌日の対象を示唆していると読める（店は「公約等とは関係ない」と書くが、常連にとっては既知の合図）。
- 次に価値がありそうなのは、**週間・月間の「オススメ」で機種を名指しする投稿**（期間つき）。

## 3. 取らなくてよいもの

営業時間・抽選時刻・開店告知、取材告知（/slot 側で取得済み）、新台・増台、景品・交換会、会員登録・アプリ案内、「公約等は当店と関係ありません」などの注意書き、店長ブログ。

## 次の手

1. 「1.夜の機種カード」の店舗を対象に、機種と枠の色（または型）を毎日記録する（`scripts/line_hints.py`、まず UNO系列・グリーン・SKIP関内）。
2. 記録を数週間ためて、翌日の台データ（/slot 側）と突き合わせ、色や機種に意味があるかを確かめる。
3. 「2.週間・月間オススメ」は機種と期間だけを抜き出す。
