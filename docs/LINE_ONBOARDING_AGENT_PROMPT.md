# 他AIへの依頼プロンプト（LINE店舗追加）

下の「依頼文」をそのまま貼り付けて使います。`<…>` の部分だけ書き換えてください。
依頼先のAIは、Mac上の `~/projects/slot-line` でコマンド実行と画像の閲覧ができる必要があります。

- **画像を見られるAI**：モードAで依頼する（全部の作業ができる）
- **画像を見られないAI**：モードBで依頼する（友だち追加と記録の再生成だけ。画像の判断はしない）

---

## 依頼文

```text
あなたは slot-line リポジトリ（~/projects/slot-line）で、パチンコ店の公式LINEを専用Android端末に友だち追加し、
各店舗の「最新情報」の取り方を分類する作業を行います。

## 最初に必ずやること
1. docs/LINE_ONBOARDING_MANUAL.md を最初から最後まで読む。手順はすべてこのマニュアルに従う。
2. マニュアル §2「絶対にやってはいけないこと」を守る。特に次の6つ。
   - LINEでメッセージ（文字）を送らない
   - 「認証」「許可する」（LIFF同意画面）を押さない
   - ブロック・トーク削除・端末の設定変更をしない
   - 本人確認できない店舗は友だち追加しない
   - 1店舗につきボタンは1回まで。わからないボタンは押さない
   - 新規の友だち追加は1日20件まで。「friend_add_blocked」が出たらその日は終了
   - 端末の画面操作はマニュアルのスクリプトだけで行う。adb で直接タップしない
     （例外は画面の点灯と Back キーだけ）。トーク一覧の行を座標で開かない
   - 店舗以外のトーク（個人・グループ）やトーク一覧の画面を保存・commitしない。このリポジトリは公開されている
3. マニュアル §3 の準備（端末の接続、縦向き、画面ON）を確認する。横向きなら作業せず報告する。

## 今回の作業（モード<A または B>）
<モードA：画像を見られるAIの場合>
- まずマニュアル §8「次の人がやること」を片付ける。
  ボタンを押すときは、必ず Step 4 の 4-1 → 4-2（dry-run）→ 4-3 → 4-4 の順に行う。
  dry-run の画像で「正しい店舗」「押す位置に最新情報ボタンがある」を目で確かめてから本番を実行する。
- commit の前に Step 5.5 の自己チェック表を作り、全項目が「はい」になってから進む。
- 余裕があれば、新しい店舗を最大 <件数、20以下> 件、Step 1〜7 で追加する。
  §8 に書いてある「その日のLINE ID検索の使用回数」も合計に含めること。

<モードB：画像を見られないAIの場合>
- Step 1〜2（候補選び・友だち追加）だけを最大 <件数、20以下> 件行う。
- Step 3〜5（画像を見る・ボタンを押す・review記入）はしない。
  追加できた店舗は、マニュアル §8 の「途中の作業」の表に「画像レビュー未」として足す。
- Step 6 は `python3 scripts/onboard_line_targets.py registry` だけ実行する。
- Step 7 でテストし、commit / push する。

## 判断に迷ったら
- マニュアル §6 に当てはまるもの（名前の不一致、同じLINE IDが複数店舗に載っている、移行案内、
  「お知らせ」などの曖昧なボタン、LIFF同意画面など）は、自分で決めずに作業報告に書いて止める。
- 「見えない＝ない」と判断しない。証拠が足りなければ unresolved のままにする。
- 想定外の画面・エラーが出たら、無理に続けずに状況（コマンド、出力、スクリーンショットのパス）を報告する。

## 作業が終わったら、次の形式で報告する
1. 追加できた店舗数と、追加できなかった店舗（理由つき）
2. 分類ごとの件数（Type A / B / C / unresolved）
3. ownerに確認したいこと（あれば箇条書き）
4. commit のハッシュ
5. その日に使ったLINE ID検索の回数
6. マニュアル §8 を今の状態に書き換えたかどうか
7. Step 5.5 の自己チェック表（店舗ごと：分類・根拠の画像パス・その画像で結果が見えるか・押した回数）
```

---

## 使うときのメモ（owner向け）

- 1回の依頼で扱う件数は、新規追加20件以内にしてください。LINEの検索回数の上限を超えると、丸1日以上追加できなくなります。
- 依頼先から「ownerに確認したいこと」が来たら、回答を添えて次の依頼を出してください。例：
  「〇〇店（LINE上は△△）は同じ店舗です。`--owner-confirmed-name` で追加してください」
- 依頼先がマニュアル §8 を更新していなければ、次の依頼で最初に更新させてください。
- 報告が届いたら、Step 5.5 の自己チェック表を見て、Type B/C の根拠画像を何件か自分で開いて確かめるのがおすすめです。
- 最初の依頼の件数：§8「次の人がやること」の3件だけを「新規追加0件」で依頼し、結果を確認してから新規追加を任せてください。
